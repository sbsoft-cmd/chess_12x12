# chess_12x12
chess

Это прототип нового шахматного концепта.
Доска размером 12х12.
По 12 пешек с каждой стороны, первым ходом пешка может пойти на 3,2,1 клеток вперед, впоследствии на 1,2, может взять на проходе.
При достижении посленей горизонтали превращается в фигуру.
Есть набор из стандартных фигур.
Также есть три нестандартные фигуры - джинн, орел и гепард.
Джинн - это тот же ферзь, но дополнительно может перескочить через свою фигуру, если следующая за ней клетка свободна.
Гепард - это та же ладья, но дополнительно может перескочить через свою фигуру, если следующая за ней клетка свободна.
Орел - это тот же конь, ходит буквой Г, только немного дальше.
Выигрывает тот, кто ставит мат королю противника.
