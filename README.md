# chess_12x12
chess

Это прототип шахмат для доски размером 12х12.

По 12 пешек с каждой стороны, первым ходом пешка может пойти на 3,2,1 клеток вперед, впоследствии на 1,2, может взять на проходе.

При достижении последней горизонтали превращается в фигуру.

Есть набор из стандартных фигур.

Также есть три нестандартные фигуры - джинн, орел и гепард.

Джинн - это тот же ферзь, но дополнительно может перескочить через свою фигуру, если следующая за ней клетка свободна.

Гепард - это та же ладья, но дополнительно может перескочить через свою фигуру, если следующая за ней клетка свободна.

Орел - это тот же конь, только немного дальше.

Рокировка здесь принципиально отличается от рокировки в классических шахматах.
Рокироваться могут любые две фигуры одного цвета, при этом фигуры меняются местами.
При этом: конь может рокироваться с любой фигурой если фигура находится под боем этого коня.
Орел может рокироваться с любой фигурой если фигура находится под боем этого орла.
Остальные фигуры могут рокироваться, если они бьют другую свою фигуру и между ними только пустые клетки.
Король может рокироваться только с фигурой, которая стоит на последней горизонтали - для белого короля это первая горизонталь, для черного это двенадцатая горизонталь.

Выигрыш как обычно - нужно поставить мат королю противника.
